# Security and privacy

Token Overdrive reads local Codex session logs only after the user grants the
app access to the relevant local folder. It never uploads those logs.

Microphone mode uses transient volume only. Audio is neither recorded nor
stored.

Future ChatGPT account connections will require explicit user consent. Tokens,
refresh credentials and chat content must never be written to logs, analytics,
source control or support transcripts.

Please report security issues privately to the project maintainer before filing
a public issue.
